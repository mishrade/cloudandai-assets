# cloud.and.ai public assets

Rendered social media assets for cloud.and.ai, hosted publicly so the Buffer API can fetch them.

Buffer's `create_post` / `edit_post` accept media only as a direct, publicly downloadable
http(s) URL. These files are served from raw.githubusercontent.com for that reason.

- `slides/` carousel and post images (1080x1350 / 1080x1080 PNG)
- `video/` 9x16 shorts (MP4, H.264)

Generated by `scripts/render-slides.js` and `scripts/make-short.js` in the private
social-media-agent project. Fonts are not redistributed here; they are already
rasterised into the PNGs.
